# 使用手册：从一部小说到一集成片

> 这份手册是给**做内容的人**看的，不讲技术。
> 你只要记住一件事：**你要操心的，只有剧情怎么走、分镜里画面和台词细节对不对**。
> 其余的（按模型改写提示词、调用哪个模型、显存怎么排）都是系统在后台自己做的，你不用管，也看不到。
>
> 手册只写**现在真能用**的功能，不写还没做的。

---

## 一、先认识这几个入口

打开平台，左侧导航从上到下是：

| 入口 | 干什么用 |
|---|---|
| **我的项目** | 你的主战场。一部剧一个项目，所有东西都挂在项目下。**平时从这里开始。** |
| 我的画布 | 自由排版、局部创作、跟画布助手对话。 |
| 影视流水线 | 单独看/管一次「跑批」的记录，能续跑、能看历史。 |
| 生图工作台 | 单独出一张图、试模型。 |
| 视频创作台 | 单独出一段视频。 |
| 提示词库 | 供高级用法，日常可不碰。 |
| **我的资产** | 全局素材总览，**只有这里能彻底删除文件**。 |
| **任务管理** | 所有正在跑、跑过、失败的任务清单。 |
| 配置 | 接模型、设默认参数。 |

**日常标准动线**：我的项目 →（进去以后）规划·剧本 → 分镜 → 资产 → 关键帧 → 视频·后期。

## 二、做出成片的五步

### 第 0 步：建项目 + 导入小说

1. 左侧点 **「我的项目」**。
2. 点 **「新建项目」**（页面上叫「新建项目」，一部剧=一个项目）。
3. 填这些（照着填就行）：
   - **剧名**：随便起，能认出来就行。
   - **原文**：可以直接粘贴小说正文，也可以上传小说文件（txt 等）。**也可以先不填，进项目后再补。**
   - **风格锚点**：整部剧统一的画面风格，比如「二维动画」「写实电影感」。一句话就行。
   - **视频模型**：决定出片用什么模型。**选了它，下面「每集时长」能选的值会跟着变。**
   - **每集时长**：只能从下拉里选（比如 H3 模型只有 5 / 10 / 15 秒可选）。**时长是跟着模型走的，不能随便填。**
   - **集数**、**画面比例**（横屏/竖屏）、题材/基调/视觉形式等：按需要填。
4. 点确定。项目建好，进入**项目总览页**。

> 你在总览页会看到：规划参数、集、关联流水线、完成度检查表、风险提示，以及六个工作区入口。
> 右上角还会告诉你 **「下一步」** 该做什么 —— 照它点就行。

### 第 1 步：生成剧本（「规划·剧本」工作区）

1. 项目总览点 **「规划·剧本」**。
2. 如果还没导入原文，这里可以**导入/替换原文**。
3. 点 **运行「剧本」**（第一次会让你「新建流水线并运行」，直接确认）。
4. 会看到进度。剧本分三小步跑：**读原文 → 分集规划 → 逐集剧本**。
   - 系统会先告诉你**预计要花多久**。如果是很长的书，会切成很多块，可能要跑几十分钟。
   - 跑到一半想停：点 **「取消运行」**。
   - 停了以后可以 **「续跑」**，已经跑完的块不会重跑。
5. 跑完，看剧本内容。**这一步是你要重点看的**：人物、场景、每一集、每场戏对不对。
6. 看完确认，才允许往下走。

> 💡 如果原文特别长，会让你先确认一次再开跑（避免你不知情就等很久）。

### 第 2 步：生成分镜（「分镜」工作区）

1. 剧本确认后，进 **「分镜」** 工作区。
2. 点 **运行「分镜」**。
3. 跑完得到一列**镜头**，每个镜头有：景别、机位、动作、台词、声音、画面描述等。
4. **这一步也是你要重点看的**：镜头顺序、每个镜头的画面细节、台词对不对。
5. 镜头可以**逐个改**：点开某个镜头编辑它的内容。镜头的编号是固定的，改内容不会打乱编号。

> 画面上若写了文字（招牌、字幕等），系统会**逐字照抄**你写的内容去生成，不会翻译、不会改。

### 第 3 步：服化道 / 资产（「资产」工作区）

1. 进 **「资产」** 工作区。
2. 点 **运行「服化道」**。
3. 系统会为**角色**生成参考图（正脸特写、三视图方向），为**场景**生成空场母版图。这些图会**自动挂到项目资产上**。
4. 每个角色/场景一行，带缩略图。**点缩略图是在页面内弹窗放大**（不会跳新页面）。
5. 不满意可以**换一张**（切换采用的产物），或登记自己的参考图。

> 这些参考图后面会自动拿去「锁角色」——同一个角色在不同镜头里长得一样，就靠它。

### 第 4 步：生成关键帧（「关键帧」工作区）

1. 进 **「关键帧」** 工作区。
2. 点 **运行「关键帧」**。
3. 系统按镜头逐个出图。**一个镜头一次出好几张（默认 4 张）**，让你挑。
4. 出图过程：
   - 你会看到每个镜头的**候选图缩略图**，一行一个镜头，还标着用的模板、种子、用了几张参考图。
   - **点缩略图弹窗预览**，弹窗里能左右切换对比。
   - 哪个镜头出得不好：可以**单独重跑这个镜头**（换一版），不用整集重来。
   - 个别的镜头因为**缺角色/场景参考图**出不了：它会明说「缺参考图」，不会偷偷糊弄。
5. 挑好、确认关键帧，才允许往下走。

> 一个镜头一次出多张是为了让你有得挑。只要有一张达标，系统就不会再浪费算力重复出。

### 第 5 步：生成片段 → 导出成片

1. 进 **「视频·后期」** 工作区。
2. 点 **运行「片段合成」**：系统按镜头逐个出视频片段。
3. 片段出来后，可以逐个播放、看候选、挑一段用。**片段齐了，成片不会自动拼**（这是有意设计：要你先看过片段再决定拼）。
4. **关于「拼成成片」的现状（照实说）**：把片段拼成一条完整成片的功能**在后端已经有了**，但**当前网页界面上还没有对应的按钮** —— 拼接这一步目前不通过页面点击完成。
   - 前提是：**所有片段都成功、且都有文件**，否则拼不了（会告诉你差哪几个）。
5. 一旦项目里有了成片，就可以在**项目总览页**点 **「导出交付包」**，把成片、封面、字幕、交付清单打成一个 zip 下载。
   - 如果还没有成片，这个按钮会提示「项目还没有已完成的成片，无法导出交付包」。

> 出片是本地显卡干的，一集要跑一阵；显卡一次只能跑一个任务，多个片段会排队，属正常。

## 三、任务在哪看、怎么看

- 左侧 **「任务管理」**：所有任务的清单，能看到排队中 / 生成中 / 已完成 / 失败。点 **「刷新」** 更新。
- 工作区里跑阶段时，页面本身会显示进度和步骤条，也能取消。
- 生图工作台、视频创作台有自己的任务卡，刷新页面任务也不会丢（进度都从服务器读）。

## 四、素材归档与删除（重要）

- **在正常创作动线里，你只能「归档」**：归档是可逆的，之后还能恢复。
- **只有「我的资产」页面能彻底删除文件**：
  1. 左侧点 **「我的资产」**。
  2. 切到 **「全部产物」**。
  3. 勾选要删的，点 **「彻底删除」**，会弹一个二次确认框，框里列出要删的清单和引用警告。
  4. **被别处引用着的素材，不让选、也删不掉** —— 会告诉你被谁引用了，先去解除引用。
- 默认只看在用的素材；打开 **「显示已归档」** 能看到归档的，还能**恢复**。

> 记住一句话：**动线上只归档，彻底删除只在「我的资产」。**

## 五、常见问题（FAQ）

**Q：跑失败了怎么办？**
去「任务管理」看是哪个任务失败了、失败原因是什么。回到对应工作区，可以**只重跑失败的那一条**（比如某个镜头），不用整条流水线重来。整个阶段失败了，在「影视流水线」页可以**续跑**，已经完成的部分不会重做。

**Q：模型下拉里为什么没有我想要的模型？**
模型清单是**只读登记表**，不是系统去网上现查的。想要某个模型出现，得先在「配置」里把它的渠道/模板登记好、同步进模型清单，它才会出现在下拉里。

**Q：我的提示词会不会被系统偷偷改掉？**
不用担心这件事。**按模型改写提示词是后台的内部动作，你看不到、也不用管**。你要盯的只有两件事：**剧情怎么走**（小说/剧本）、**分镜里的画面和台词细节**对不对。你只负责选模型、点生成。

**Q：为什么「每集时长」只有几个固定值可选？**
因为时长是跟着视频模型走的。每个模型能出哪几个时长是固定的（比如 H3 只有 5/10/15 秒）。想换时长档位，就换模型。

**Q：为什么一个镜头一次给我出好几张图？**
让你挑。出一张你可能不满意，一次出几张（默认 4 张）横向对比，挑一张用即可。

**Q：片段都出完了，为什么成片还没自动出来？**
这是有意设计的：**片段齐了不等于成片完成**，要你先看过片段再说。另外照实说明：把片段拼成整片的动作**目前网页上还没有按钮**，这一步由后端执行；成片产出后才能在「导出交付包」里导出来。

**Q：为什么有些镜头显示「缺参考图」出不来？**
那个镜头用到了没被选定基准图的角色/场景。去「资产」工作区给对应角色/场景选定一张参考图（或重跑「服化道」生成），再回来重跑这个镜头。

**Q：跑到一半页面关了 / 服务重启了，会白跑吗？**
不会。剧本是分块跑的，已完成的块存在服务器上。回到项目，从「影视流水线」**续跑**即可。生成类的任务重启后会明确标成「中断」，重新跑一下就行。

**Q：上传的图、生成的图会不会丢？**
项目和生成记录都在服务器上。刷新页面、换台电脑登进来，还能在「我的项目」里接着做。

## 六、名词小抄

| 词 | 大白话 |
|---|---|
| 项目 | 你的「一部剧」，所有内容挂在它下面。 |
| 工作区 | 项目里的一个大步骤页面（剧本/分镜/资产/关键帧/视频）。 |
| 阶段 | 流水线的一步：剧本 → 分镜 → 服化道 → 关键帧 → 片段合成。 |
| 门禁 / 待确认 | 上一步没确认，下一步就点不了。这是故意的。 |
| 关键帧 | 一个镜头里的定格画面（首帧/尾帧）。 |
| 候选 | 同一个镜头一次出的多张图/多段视频，供你挑。 |
| 参考图 | 用来锁定角色长相/场景样子的图。 |
| 片段 | 一个镜头对应的一小段视频。 |
| 成片 | 所有片段拼起来、配好音和字幕的最终视频。 |
| 归档 | 收起来、可恢复，不是删除。 |
