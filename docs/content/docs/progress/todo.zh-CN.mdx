权威排序、依赖关系与验收标准见 `docs/content/docs/progress/development-plan.md` §8；产品视角的优先级见 `prd.md` §6。以下只列尚未开工的项。

- **P0-b run 可恢复**：前端 `run` 是裸 `useState`，刷新即永久丢失，而后端仍在跑、仍在烧额度；服务端**早就有** `GET /api/pipeline/runs`，前端没封。要持久化 runId、补列表客户端、允许命名（现在一律落「未命名流水线」）、加离开页面拦截。
- **P0-c 命名重构 + Project 服务端实体**：`CanvasProject` 改名 `Canvas`，新实体 `Project` = 一部剧、可含多个画布。**必须在写新代码之前做完**，否则 `projectId` 的歧义会扩散（`CanvasAgentSnapshot.projectId` 现在填的是画布 id）。
