# 短剧创作方法论（通用版）

> 本文档是一套**与具体 AI 工具无关**的短剧/微电影生产方法论文档，源自豆包工作环境的"短剧创作"技能，已去除宿主工具名与专有语法。任何支持文本生成、图像生成、视频生成的大模型工具（ChatGPT、Claude、Kimi、即梦、可灵、Runway、本地模型等）都可直接按本文档执行。
>
> 使用方式：整篇喂给目标 AI，或按阶段分章节喂入；AI 按"规划 → 剧本 → 分镜 → 资产 → 关键帧 → 视频提示词"六阶段推进，每个阶段完成并经用户确认后再进入下一阶段。

## 1. 适用范围与核心原则

### 承接范围

- **主承接**：单集 5-10 分钟以内的短篇短剧、微电影、剧情短片、动画短片、宣传片、预告片、广告剧情、单条剧情短视频。
- **可承接**：长篇短剧（多单元、几十集、跨集主线）的完整剧本创作，但须向用户声明长篇幻觉风险（见阶段 1"长篇幻觉风险声明"），并分批输出。

### 三条最高优先级原则

1. **用户确认门禁**：剧本、分镜、资产、关键帧、视频的每一个阶段完成后，必须停下来请用户确认，收到"确认/没问题/继续/ok"等明确许可后才能进入下一阶段。禁止擅自推进。
2. **正式交付原则**：所有用户可见产物（规划报告、剧本、分镜表、资产图、关键帧、视频、提示词包）都应保存为正式文件交付给用户审阅，不要在聊天正文里整段粘贴或只发链接。每生成一张图/一个视频，立即交付并请求确认，不攒批。
3. **一致性锚点原则**：从剧本阶段锁定"风格锚点"（一句话风格定位，如"王家卫风格的电影""3D 玄幻风格"）后，资产、关键帧、视频所有阶段的提示词首句必须一字不差沿用同一锚点，禁止中途简化、替换或省略。

### 单段视频时长说明

单段视频时长取决于所用生视频模型的能力上限（当前主流模型通常支持 5-15 秒，部分支持 30 秒）。**规划分镜前先确认所用模型支持的最大时长，分镜片段按该上限切分**；若模型支持 30 秒，可把两个 15 秒片段合并为 30 秒版本。

## 2. 六阶段总览与阶段依赖

```text
规划(planner) → 剧本(scriptwriter) → 分镜(storyboard) → 资产(assets) → 关键帧(frame) → 视频提示词(prompt)
```

阶段之间存在依赖，按顺序推进；发现上游缺失时回到最早缺失的阶段补齐。

| 阶段 | 输入 | 输出 |
|---|---|---|
| 0. 规划 | 用户想法/素材 | 规划报告、参数确认表 |
| 1. 剧本 | 故事主题/人物/冲突 | 剧情梗概 + 人物小传 + 主要故事场景 + 完整剧本（四段产物） |
| 2. 分镜 | 完整剧本 | 章节 → 片段 → 镜头三层分镜表 |
| 3. 资产 | 剧本 + 分镜 | 角色/场景/道具设定图与视觉基准 |
| 4. 关键帧 | 分镜 + 资产 | 每片段 1-3 张关键帧图（30s 片段 2-5 张） |
| 5. 视频提示词 | 分镜 + 资产 + 关键帧 | 可执行视频提示词包与生成视频 |

**完成度检查表**：

| 阶段 | 要求 | 是否完成 | 缺失内容 |
|---|---|---|---|

| 2. 分镜切分 | 章节切分 + 片段规划（按模型时长上限） | 是/否 | |
| 3. 资产设定 | 角色、场景、道具资产与参考图 | 是/否 | |
| 4. 关键帧 | 每个片段依判定标准锁定 1-3 张关键帧图 | 是/否 | |
| 5. 视频提示词 | 可执行视频提示词与生成参数 | 是/否 | |

## 3. 阶段 0：项目规划与参数澄清

### 澄清清单

每轮只问 1-3 个关键问题。用户说"你来定""随便"时，选择合理默认值并继续规划（真正生成前仍需确认参数）。

| 阶段 | 需要澄清 |
|---|---|
| 规划 | 目标、产物形式、受众、单集总时长（5-10 分钟）/长篇总集数、剧作基调（微电影三幕式 / 短视频钩子驱动）、已有素材、希望从哪个阶段开始 |

| 资产 | 角色、场景、道具、视觉风格、参考图用途、一致性锚点、是否需要角色介绍视频 |
| 关键帧 | 哪些章节/片段、关键帧判定标准、场景/角色引用、构图、光影 |
| 视频提示词 | 模式（文生视频/图生视频）、目标片段时长、比例、参考资产、已锁定关键帧列表、台词/声音、负向约束、批次数量 |

## 4. 阶段 1：剧本创作

### 4.1 必须交付的四段产物（缺一不可）

1. **剧情梗概**（约 1500 字）：单一连贯叙事文本，覆盖起承转合——故事起点与主角初始处境、核心冲突登场、事件升级与转折、高潮反转、落点/情感闭环。短篇 1500 字覆盖单集；长篇 1500 字覆盖全剧主线，另配分集大纲表。
2. **人物小传**：主角、配角、反派三类，每类至少一位。每位含：一句话定位、性格（3-5 个具体特质，用行为倾向描述而非抽象形容词）、动机（核心动机 + 底层驱动力）、成长弧线（开场 → 中段动摇 → 结局蜕变，写清转折触发事件）、视觉方向、关键道具/记忆点。**反派必须写清"合理性动机"（为什么这样做）与"惩罚落点"（如何得到实质惩罚或明确失败）。**
3. **主要故事场景**：短篇 2-4 个 / 长篇 4-8 个核心场景，每个场景锁定：名称、类型/功能（主场景/次场景/回忆梦境）、空间概念方向、情绪氛围基调、叙事性关键陈设、常见时间/内外景。
4. **完整剧本**（分集分场专业格式）：见 4.3。

**场景取用硬约束**：完整剧本每一场戏的表头 `场景名` 必须严格从"主要故事场景"清单中选取；剧情确需新增场景时，先回填场景清单并向用户说明，确认后再继续。禁止在剧本正文里自由新增未登记的场景。

### 4.2 长篇幻觉风险声明（总集数 > 10 集时强制前置）

生成前必须向用户一次性声明风险，得到确认后才可继续：

> 提示：您要求生成 N 集完整剧本。当集数超过 10 集时，模型可能出现剧情或人设漂移（例如伏笔遗忘、角色动机前后不一、关键道具/场景失守）。生成过程中如您发现某一集与前文剧透、人设或世界观出现矛盾，请随时指出，我会针对该处进行回填校正或整段重写。

同时给出兜底建议（供用户选择）：
- 拆成独立短篇/单集样片分别制作；
- 改用专门的长篇短剧生产工具；
- 保留长篇但同意承担漂移风险，由用户在生成过程中随时点位纠错。

**长篇分批交付**：完整剧本按"首批 3-5 集 → 交付 → 用户确认 → 下一批"推进（单集 3 分钟以内可 5 集/批，5 分钟以上建议 3 集/批）。每批开头标注集数区间并复述上一批关键事件与埋下的伏笔；每批结尾标注 `【伏笔待回收：XXX（预计第 X 集）】`。

**分集大纲附表**（长篇必配，降低漂移风险）：

```markdown
| 集号 | 集名 | 核心事件 | 情绪节拍 | 关键伏笔/回收 |
|---|---|---|---|---|
| 第1集 |  |  | 开场钩子 |  |
| 第2集 |  |  | 冲突展开 |  |
| ... |  |  |  |  |
```

### 4.3 完整剧本格式规范

剧本头（每部剧本开头一次）：

```markdown
《[剧本标题]》
类型：[短篇短剧 / 微电影 / 剧情短片 / 动画短片 / 广告剧情 / 长篇短剧]（如为长篇，注明总集数）
风格：["某某风格的电影" 或 "3D玄幻 / 2D水墨 / 2D日漫赛璐璐" 等，必须是一句话锁定，禁止写"电影风格""高级质感"等模糊表述]
标签：[题材关键词 + 情感关键词]
人设：[一句话高浓缩人设对撞]
单集时长：[X 分钟]  |  剧作基调：[微电影三幕式 / 短视频钩子驱动]
```

分集与分场格式：

- **分集标题**：`第X集`，独占一行。
- **场次编号**：`X-Y`（X 为集号、Y 为该集内场次序号）。
- **场景表头**：`场次编号 场景名 [日/夜] [内/外景]`，例：`1-1 茶室 日 内`。
- **人物**：单独一行列出该场人物；画外音用 `角色名+VO`。
- **动作提示**：以 `△` 起首，只写客观可拍摄的动作/调度/道具状态/镜头暗示，**不写心理活动和情绪形容词**（情绪通过动作外化）。
- **对白**：`角色名: 台词内容`；括号内可加简短情绪/动作提示；特写、内心独白用 `（特写）`、`（内心）` 前置。
- **旁白/画外音**：`角色名VO: 内容`。
- **情绪节拍标记**：关键台词/动作末尾用 `【节拍：XXX】`（如 `【节拍：破冰】`、`【节拍：反转】`），供分镜阶段判断节奏。

**剧本样例**：

```markdown
《最后一封信》
类型：微电影（1 集）
风格：是枝裕和风格的电影
标签：都市治愈 + 父子和解 + 遗物开启
人设：情绪克制的都市白领儿子×一辈子沉默的老式父亲
单集时长：6 分钟  |  剧作基调：微电影三幕式

第一集

1-1 旧公寓门口 日 外
人物：林远
△（远景）林远背对镜头站在旧公寓门口，右手推开吱呀作响的木门，尘埃在门缝斜光中缓缓浮动。
△林远停在门框中央三秒，没有立即迈步进去。
林远VO：父亲走后的第七天，我第一次踏进这里。【节拍：开场钩子】

1-2 旧公寓客厅 日 内
人物：林远
△林远缓缓走进客厅，视线扫过书架上父亲的旧照片，眉头轻蹙。
△（近景）林远走到书架前，右手抬起，指尖轻抚玻璃相框，停在父亲肩膀上。
△（特写）指尖在玻璃相框上停留三秒后缓慢滑落，指腹沾了一层薄灰。
```

### 4.4 风格字段：真人电影大师参考库

**风格路径判定**：只有两条强信号才切"非真人"：①用户直接指定画面制作形式（3D/2D/水墨/赛璐璐/绘本等）；②内容本身无法真人拍摄（非人形主角等）。**题材本身（仙侠/玄幻/科幻/古风）不构成非真人信号**——题材可以拍真人。无非真人强信号时默认走真人电影，风格字段写"某某风格的电影"。

**真人电影六大流派参考库**（澄清阶段按题材/情绪基调选 1 位主锚点大师）：

| 流派 | 大师锚点 | 适配题材/情绪 |
|---|---|---|
| 东方生活流/家庭治愈 | 是枝裕和（家庭日常、餐桌戏、克制情感高潮）；李安（早期华语）；侯孝贤（长镜头生活流）；岩井俊二（青春过曝、逆光） | 治愈、亲情、青春 |
| 港风霓虹/怀旧胶片 | 王家卫（手持慢速快门、高饱和霓虹、拖影）；杜可风摄影；贾樟柯（纪实乡镇） | 怀旧、年代 |
| 极简对称/高饱和作者美学 | 韦斯·安德森（绝对对称、马卡龙色板）；PTA（复古胶片、慢推）；昆汀（章节化、复古高饱和） | 广告剧情、短剧亮相戏 |
| 极简冷冽/精密构图 | 大卫·芬奇（低调冷灰、精密对称）；库布里克（一点透视、冷冽）；罗杰·迪金斯（逆光剪影）；诺兰（大远景+手持贴脸） | 悬疑、独立文艺、高级暗调 |
| 诗性自然/影展作者 | 泰伦斯·马利克（广角低机位、诗性旁白）；阿彼察邦（东南亚湿热、超现实梦境）；河濑直美 | 影展参赛短片 |
| 社会现实主义/纪实感 | 达内兄弟（手持贴身跟拍、原生光）；肯·洛奇（工人阶级纪实） | 社会议题 |

**题材/情绪→大师速查**：治愈家庭→是枝裕和；青春逆光→岩井俊二；怀旧年代→王家卫/贾樟柯；极简对称广告→韦斯·安德森；悬疑独立文艺→大卫·芬奇/库布里克；社会议题→达内兄弟/肯·洛奇；影展诗意→马利克/阿彼察邦。

### 4.5 单集章节结构

短篇单集必须切分为 **3-5 个叙事章节**，每章节承担明确叙事功能：

| 单集总时长 | 章节数 | 单章节时长 | 每章节片段数（按 15s/段） |
|---|---|---|---|
| 5 分钟 | 3 章节 | 约 100 秒 | 6-7 段 |
| 6 分钟 | 4 章节 | 约 90 秒 | 6 段 |
| 8 分钟 | 4 章节 | 约 120 秒 | 8 段 |
| 10 分钟 | 5 章节 | 约 120 秒 | 8 段 |

- **微电影三幕式**：铺陈（20-25%）→ 事件与冲突（40-50%）→ 高潮与落点（25-30%）。
- **短视频钩子驱动**：3 秒钩子 + 铺垫（15-20%）→ 加剧压迫/主角蓄力（30%）→ 身份暴露/首波打脸（30%）→ 终局清算/爽点释放（20-30%）。

### 4.6 写作法则

#### A. 短剧向法则（钩子驱动 / 爽感释放）

- **黄金开局**：前 15-30 秒抛出核心矛盾或强悬念。
- **高频反转**：每章节至少一次反转；避免超过 15 秒无信息增量的镜头。
- **收束优先**：结尾必须给明确落点（惩罚/反转/行动号召/情感闭环），短篇不用"待续"收尾。
- **压迫要具体，释放要痛快**：对手阻挠必须有具体恶劣行径，主角反击必须降维打击。
- **反差原则**：人设反差（弱小外壳+强大内核）、情节反差、台词反差。
- **用动作外化情绪**：不说反派多坏，直接让他踩碎主角的救命药。
- **反派惩罚铁律**：短篇必须让反派在本集内得到实质惩罚或明确失败。

#### B. 微电影向法则（三幕式 / 情感沉淀）

- **单一核心事件**：一部微电影只承载一个核心事件/一次情绪转变/一个价值追问。
- **允许留白**：2-3 秒静态凝视、无对白空镜、环境音铺陈是必需成本。
- **落点优先"情感闭环"**：结尾是和解/释怀/无声告别，不追求打脸释放；对立面可象征化（"父亲的沉默""过去的自己"），不必人格化反派。
- **情绪靠"物件 + 光影 + 留白"承载**：一封信、一块怀表、一张旧照片承担的比台词更多。
- **台词克制、去戏剧化**：允许沉默、答非所问、一句话说一半；避免"我终于明白了……"式总结陈词。
- **旁白使用节制**：只出现在开场与结尾，中段用画面 + 环境音。
- **角色少即是多**：主要角色 2-4 位。
- **光影是第一叙事语言**：自然光、逆光、剪影、色温冷暖切换承担情绪转折。

### 4.7 常见题材与受众心理参考库

（供用户未指定题材时选用，与剧作基调对齐）

**短剧向 · 个人主义爽感**（欧美市场突出）：重生/预知/无限流、穿越异世界、末世囤货生存、狼人/天选伴侣、吸血鬼/黑帮大佬、禁忌之恋/离婚觉醒、系统修仙升级流。

**短剧向 · 集体主义爽感**（国内市场统治）：掉马甲/隐世大佬（战神/龙王/首富）、真假千金/豪门上位、年代/四合院、婆媳伦理/手撕极品亲戚、萌宝/天才儿童、衣锦还乡/家族正名。

**微电影向**：
- 情感共鸣型：亲情和解、异地离别、老友重逢、临终告别/阿尔茨海默、离婚后独处。
- 治愈自愈型：深夜食堂/便利店哲学、辞职返乡、一日限定关系、独居美学、宠物告别。
- 社会议题型：打工人（外卖/网约车/35 岁裁员）、教育焦虑、老龄化/空巢、性别议题、原生家庭代际创伤、AI 与人性。
- 品牌商业型：品牌作为"情感转折的助手"出现（一杯咖啡/一次快递/一个 app 提醒），不在结尾加广告 slogan。

> 若所用工具提供联网搜索能力，且用户题材方向模糊，可先用搜索能力查近期热门题材再确定主题；工具不可用时直接按上面题材库选定方向，不要阻塞流程。

## 5. 阶段 2：分镜切分

### 5.1 三层结构与切分规则

把已确认剧本拆为 **章节 → 片段 → 镜头** 三层：

- **章节继承**：直接继承剧本阶段确认的 3-5 个叙事章节，不重新设计。
- **片段切分**：每章节内部按"模型支持的单段时长上限"（如 15s）连续切分，片段时间戳在章节内首尾相连。
- **时间戳连续**：整集从 `00:00` 开始，跨章节连续不重置。
- **镜头密度按剧作基调分档**：短剧向每 15s 片段 6-10 个镜头（高潮可上探 10-12 个）；微电影向每 15s 片段 3-5 个镜头（允许 1 个 5-8 秒呼吸镜头）。
- 双版本需求（15s + 30s）时，先按 15s 完整切分，再给出 30s 合并规则（相邻 2 个 15s 片段合并），共享同一批镜头信息。

### 5.2 分镜节奏速查表

**短剧向（钩子驱动）**：

| 单个镜头时长 | 节奏 | 对应单段镜头数(15s) | 典型剧情场景 |
|---|---|---|---|
| 1-1.5 秒 | 极快（暴力剪刀流） | 10-12 | 钩子开场、冲突爆发、打脸瞬间、身份揭示、高潮清算 |
| 1.5-2.5 秒 | 快（短剧主档） | 6-9 | 对话交锋、情绪递进、伏笔铺陈 |
| 2.5-4 秒 | 中速（短剧下限） | 4-6 | 关键台词特写、爆点前呼吸、反转停顿 |

> 短剧向下限硬约束：15s 片段总镜头数不得少于 6 个；高潮/打脸/开场钩子建议 8-12 个。

**微电影向（三幕式 / 情感沉淀）**：

| 单个镜头时长 | 节奏 | 对应单段镜头数(15s) | 典型剧情场景 |
|---|---|---|---|
| 3-5 秒 | 中速（常用档位） | 3-4 | 日常互动、情感铺陈、对白交流 |
| 5-8 秒 | 慢速 | 2-3 | 静态凝视、环境空镜、光影转折 |
| 8-12 秒 | 极慢/长镜头 | 1-2 | 长凝视、无对白独角戏、结尾落点 |

### 5.3 分镜表格式

```markdown
## 第X集：[集名]

### 本集故事提要
[不超过100字]

---

### 第一章：[章节名]（本章时长：约 X 秒 / 从 mm:ss 到 mm:ss）
> 本章叙事功能：[开场钩子 / 冲突展开 / 高潮反转 / 落点 …]

#### 片段一：mm:ss - mm:ss（本段包含 X 个分镜，15s）
- **镜头1 (mm:ss-mm:ss)**：[景别｜视角类型｜机位状态｜角度与朝向] 画面内容... {台词} 『旁白』 <音效> (音乐) 【字幕】 [转场]
- **镜头2 (mm:ss-mm:ss)**：...

---

### 第二章：[章节名]（本章时长：约 X 秒）
...
```

**符号规则**：音乐 `()`、音效 `<>`、台词 `{}`、旁白 `『』`、字幕 `【】`。

### 5.4 景别与视角术语

| 景别/视角 | 定义与用途 |
|---|---|
| 大特写 | 面部局部（眼睛、嘴唇），放大极致情绪 |
| 特写 | 头肩部分，聚焦表情 |
| 近景 | 胸部以上，兼顾表情与肢体 |
| 中景 | 膝盖/腰部以上，对话场景 |
| 全景 | 全身 + 小范围环境，交代完整动态 |
| 远景 | 人物占比极小、环境为主体，强调氛围/孤独 |
| 大远景 | 人物几乎成点，史诗感开场/结尾 |
| 过肩镜头 | 从角色肩膀后方拍另一角色，增强对话代入 |
| 第三人称客观视角 | 外部观察人物动作、空间关系（多数叙事镜头） |
| POV 第一人称视角 | 模拟角色眼睛看到的画面（沉浸式体验） |

**POV 规则**：必须写明所属角色（"林远 POV"）；从角色眼睛高度出发，写清视线方向、被观看对象、可见手部/道具前景；POV 中不能出现该角色完整正脸；禁止把 POV 写成自拍、监控、无人机视角。

### 5.5 运镜术语

| 类型 | 术语 | 用途 |
|---|---|---|
| 基础运动 | 推镜 | 聚焦细节、强调重要性、制造紧张 |
|  | 拉镜 | 揭示环境、营造疏离感 |
|  | 摇镜 | 巡视场景、跟随主体 |
|  | 移镜 | 轨道平移，空间感/沉浸感 |
|  | 升降镜 | 摇臂垂直升降，宏伟/压抑 |
| 情绪表达 | 环绕运镜 | 弧形运动，戏剧张力 |
|  | 手持感运镜 | 轻微晃动，纪实感/紧迫感 |
|  | 希区柯克变焦 | 推拉+反向变焦，极度震惊 |
| 动作冲击 | 甩镜转场 | 快速摇动产生动态模糊 |
|  | 子弹时间 | 动作放慢+镜头环绕，决定性瞬间 |

### 5.6 拍摄角度与主体朝向

正面（直接交流）、侧面（轮廓/思考）、3/4 侧（最常用）、背面（神秘/疏离）、仰拍（高大/压迫）、俯拍（渺小/弱势）、平视（客观）。

### 5.7 动作规则

- **肢体细化 + 程度量化**：写清身体部位和幅度/速度/力度（缓慢抬手、快速转头、用力蹬地）。
- **优先低缓连续小动作**：缓慢行走、轻轻抬手、顺势坐下；除非剧情必须，避免狂奔、大跳、翻滚、复杂打斗（AI 视频生成不稳定）。
- **写清动作过渡与惯性承接**：借着转身惯性顺势抬手、从停顿自然过渡到举手。
- **情绪具象外化**：不用"很悲伤""非常愤怒"。悲伤=低头、肩膀微颤、眼眶泛红、攥紧衣角；愤怒=双拳紧握、下颌线紧绷、胸口剧烈起伏。

### 5.8 连续性规则

- 每个镜头结尾写明转场（`[硬切]` `[叠化]`），前后镜头因果衔接（上个镜头扔出文件，下个镜头必须有人低头看文件并反应）。
- 台词长度适配镜头时长（3 秒内只能说一两句短语）。
- **角色与道具命名强一致**：全程用同一称呼（"林远"或"黄衣小哥"），不中途改用代词/别称。
- **不用群体量词**：不写"三个人面面相觑"，写"黄衣小哥、粉裙少女、灰头发老太 面面相觑"。

**分镜阶段不指定关键帧位置**：哪些镜头要生成为关键帧图，由关键帧阶段按判定标准动态锁定。

## 6. 阶段 3：资产设定

### 6.1 角色资产

每个主要角色需要：

- **1 张横版角色设定图**（16:9）：左侧 1/3 为中性表情的超清正面脸部特写（直视镜头、五官对称、不得微侧脸）；右侧 2/3 为全身正面/侧面/背面三视图（从头到脚完整、不裁切）；纯白背景；三视图正面脸与左侧特写 100% 一致；三个视角同一发型、体型、服装。
- **工具可用时**：1 条 5-10 秒角色介绍视频（用设定图做参考，角色说一句符合人设的台词，输出音色描述）。

### 6.2 场景资产

每个主要场景需要 **6 张独立静态图**（16:9），少一张不算完成：

1. 全景氛围图（空间母版）
2. 中景图
3. 左侧视角图
4. 右侧视角图
5. 关键交互区特写
6. 反向视角图

规则：
- 第一张全景图作为空间母版，后续视角优先以全景图为参考补全。
- 6 张图必须保持相同空间结构、固定物理锚点、光源方向、色温、材质逻辑；纯场景中不能出现人物。
- **降级条款**（仅在用户明示"快进/只要核心"时启用）：可降级为"全景 + 中景 + 反向"3 张，并在验收表标注"已降级"；关键帧阶段出现缺失视角需求时必须回补。

**场景提示词质量约束**：必须写电影美学词（电影级场景设计、黄金构图、强空间纵深、前中后景层次、体积光、自然阴影、材质细节、空气透视、统一色温等），写清主光源方向、色温、明暗层次、材质反射、空间透视；禁止只用"高级、漂亮、震撼"等模糊词。

### 6.3 道具资产

关键道具需要正面/侧面/背面三视图；有重要纹理/发光/破损/象征意义时补材质细节卡。

### 6.4 风格锚点硬约束（最重要）

- 生成**所有**图像/视频的提示词**最开头**，必须加入与剧本头 `风格：` 字段**一字不差**的全局风格限定词。
- 真人路径写"某某风格的电影"（如"大卫·芬奇风格的电影"）；非真人路径写"3D 玄幻风格""2D 水墨风格"等类型词。禁止简化为"电影风格""港风""高级质感"。
- 整个项目所有资产、关键帧、视频的提示词首句必须绝对统一，不得中途替换、省略、增补。
- 若发现剧本头风格字段仍是"电影风格"这类留白写法，说明剧本阶段未完成锚点匹配，**停止资产生成，回到剧本阶段补齐**。

### 6.5 提示词颗粒度三层推演

1. **结构骨架**：图片类型、版式、构图区。
2. **语义推演**：哪些元素必须存在、为什么存在。
3. **细节填充**：位置、形态、内容、材质、关系、视觉处理、光影、色彩、纹理。

**角色描述顺序**：体态姿势 → 肤质脸型 → 五官 → 发型 → 妆容 → 饰品 → 服装（内到外、上到下）→ 面料工艺磨损 → 标志性特征。

**场景描述顺序**：物理空间结构 → 固定锚点 → 前/中/远景 → 功能分区 → 主光源方向与色温 → 材质反射 → 氛围粒子/天气 → 叙事性细节 → 电影美学约束（构图、光影、色彩、材质、纵深、画幅）。

### 6.6 角色视觉差异化策略

- **剪影差异**：体型差异、发型体积感、肩宽比例。
- **色谱分配**：为核心角色分配互补/不重叠的标志色。
- **眼型细分**：桃花眼（含情）、柳叶眼（清冷）、瑞凤眼（高傲）、杏眼（纯真）。
- **视觉钩子**：独特首饰、特定疤痕、纹身、机械义眼。

### 6.7 图生图提示词规范（通用）

以参考图为基础生成新图时，提示词按"编辑目标 + 保留项 + 编辑项 + 空间线性描述 + 风格质量约束 + 画幅比例"组织，合并为一段连贯的话：

- **编辑目标**：说明基于哪张参考图完成什么操作（补全/替换/新增/局部重绘/视角调整）。
- **保留项**：明确参考图中不能改变的主体身份、脸部特征、服装结构、场景空间、光影方向、材质细节——禁止只写"保持不变"。
- **编辑项**：逐项写清要修改的对象和动作。
- **空间线性描述**：按从上到下、从左到右、从背景到主体、从主要编辑区到次要编辑区描述。
- **多图约束**：多张参考图分别说明每张的用途和保留内容；每张目标图独立写完整提示词，不用"同上"。
- **文字约束**：可见文字逐条写清原文案与目标文案，用中文双引号框定。
- **画幅比例**：结尾写明 `16:9` / `9:16` 等。

| 资产 | 命名 |
|---|---|
| 角色设定图 | `[角色名]_设定.png` |
| 角色介绍视频 | `[角色名]_介绍视频.mp4` |

### 6.9 风格一致性目视验收（强制门禁）

交接前逐张目视核对所有资产图（不看提示词文本），判定四维度一致性：**画面质感、光影语言、色彩调性、材质表现**。

- **不通过（任一命中即回炉）**：①同一项目风格混杂（角色 2D、场景 3D 写实）；②图片与剧本头风格明显不符；③同一角色设定图与道具细节图质感语言不统一。

## 7. 阶段 4：关键帧生成

### 7.1 关键帧的定义与作用

关键帧是片段中**最能承担叙事、身份、空间与情绪锚定作用**的静态画面。两个用途：①作为图生视频的图片参考，锁定人物身份、道具状态、空间关系、光影基调；②让用户在生视频前预审关键节点画面，降低返工。

### 7.2 关键帧数量决策（不是"首/中/尾"三帧模板）

- **默认取值**：每个 15s 片段默认 1 张；只有当片段命中多条独立判定标准且分别落在不同镜头时才递增到 2-3 张（30s 片段默认 2 张，上限 5 张）。
- **禁止套模板**：不得按"首帧 + 中段 + 尾帧"三分法取 3 张；镜头位于首/尾本身不构成入选理由，必须独立命中判定标准。
- 候选不足默认取值时宁少不凑数。

### 7.3 关键帧判定标准（逐镜头评估）

凡命中一条以上的镜头即为关键帧候选：

1. **决定性瞬间**：动作或情绪抵达顶点的一帧（打脸瞬间、拥抱定格、拔剑出鞘、爆发怒吼的静止）。
2. **情节转折点**：剧情走向被改写的镜头（发现秘密、身份揭示、道具易主、关键对白落定）。
3. **身份/形象首次或再次亮相**：主要角色首次出场、换装/受伤/毁容后的形象再登场、反派身份揭示。
4. **状态突变前后**：道具状态突变（怀表完整→被踩碎）、人物物理状态突变（干净→湿透、清醒→昏迷）。
5. **角色造型/配饰改变**：主动穿脱造成的识别特征改变（摘帽子、脱外套、摘口罩、揭面具、束发→散发、卸铠甲）。
6. **空间锚点建立**：新场景首个能完整交代空间结构、光影方向的镜头。
7. **视角体系切换**：POV 与第三人称切换处的第一帧。
8. **群像结构定格**：多个主要角色站位关系被建立或重排的镜头。
9. **光影转折**（微电影向常用）：夕阳最后一道光、灯泡熄灭前后、色温冷切暖、逆光剪影建立、蜡烛点燃。

**逆向排除**：纯转场/黑场/空白字幕；高动态模糊镜头（甩镜转场、冲刺跟拍中段）；完全不出现正脸的 POV 镜头（除非是道具特写）。

**判定口诀**：写映射表时，如果某行"命中判定标准"只能写出"首帧/尾帧/开场/收束"这类位置词，说明该镜头仅因位置入选，删掉它。

### 7.4 优先级取舍（候选超上限时）

- **短剧向**：决定性瞬间 > 情节转折 > 身份/状态突变 > 造型改变 > 空间锚点 > 光影转折。
- **微电影向**：光影转折 > 情节转折 > 决定性瞬间 > 状态突变 > 造型改变 > 空间锚点。

### 7.5 关键帧命名与映射表

命名：`EPxx_CHxx_SEGxx_KFxx.png`（集-章-片段-帧序号）。

生图前必须先输出映射表（每行命中标准必须写具体名称，禁止位置性理由）：

```markdown
| 关键帧 | 集数 | 章节 | 片段 | 对应镜头 | 关键帧时刻 | 命中判定标准 | 分镜原文摘要 | 画面截取规则 |
|---|---|---|---|---|---|---|---|---|
| EP01_CH01_SEG01_KF01 | 第1集 | 第一章 遗物 | 片段一 00:00-00:15 | 镜头1 | 00:00 | 空间锚点建立 | 林远背对镜头推开旧公寓木门，尘埃在斜光中飘动 | 截取镜头1中人物、木门、斜光尘埃已到位的稳定态 |
```

**分镜绑定硬约束**：每张关键帧必须绑定已确认的分镜片段，禁止脱离分镜表自由编写新剧情/新构图/新动作；提示词只能补充光影、构图、肢体细节等不改变剧情结果的视觉细节。

### 7.6 关键帧生成方式

- 已有资产图时，**默认用图生图**（把角色/场景/道具资产图作为参考图传入），不建议脱离参考图纯文生图。
- 每次生成前整理实际传入的参考图清单与动态编号；只传本次需要的资产图，不传无关图。
- 提示词首句风格锚点与剧本头/资产锚点一字不差。
- 缺必要资产图或分镜时，停止并返回上一阶段补齐，不能脑补。

### 7.7 方向性物体空间关系（易翻车点）

手机、平板、显示器、画纸、镜子、书本、车门、武器、杯子把手等方向性物体，提示词必须写清：物体朝向谁、人物看向哪里、手部如何接触、观众看到哪一面、距离。

**方向关系公式**：`人物朝向 + 视线方向 + 物体朝向 + 手部动作 + 画面可见的物体面 + 物体与人物距离`

- 易翻车：`一个人在医院用 iPad 看剧。`
- 稳定写法：`医院病房里，一个年轻人靠坐在病床上，双手拿着一台平板电脑。平板屏幕朝向人物，屏幕背面朝向画面外侧，人物低头注视屏幕，中景侧面拍摄。`

### 7.8 构图规则

- **竖屏 9:16**（短剧/移动端）：人脸和上半身在安全区；关键道具放中部或下三分之一；双人对话保持左右空间关系；避免文字/水印/Logo。
- **横屏 16:9**（PC/电视/电影）：三分法构图；人物视线前方留呼吸空间；前/中/远景建立纵深；对峙场景保持 180 度轴线。

## 8. 阶段 5：视频提示词与生成

### 8.1 生成门禁

生成视频前必须确认：对应分镜片段（集/章/片段/时间范围/镜头原文）、每段时长（按模型上限）、画幅比例、生成模式（文生视频/图生视频/首帧驱动）、本片段关键帧列表、台词/音效/音乐/字幕要求、负向约束、批次数量（**一次最多生成 2 个视频**）。

### 8.2 参考素材引用规则

- 关键帧图承担画面元素（构图、材质、服装、光源、道具位置），**提示词文字不复述这些元素**，只描述运镜、动作、剧情、声音——避免对同一细节的双重解释。
- 每张关键帧在提示词中只声明**时间锚点身份 + 命中类型**：首帧（0 秒）/ 中段锚点（对应绝对时间点，画面必须经过此帧状态）/ 尾帧（收束画面）。
- 单张关键帧默认作为该片段首帧（若对应镜头不在 0 秒，则声明为对应时间点的中段锚点）。
- 生成非首个片段时，可把上一片段尾帧作为"承接参考帧"传入。
- 场景资产图默认不进视频阶段（关键帧已承载空间信息）；仅当关键帧数量为 1 且无法表达空间信息，或用户明确要求时，才额外传入并说明原因。

### 8.3 多主体定义规则

场景中有多个主体时，提示词开头分别定义并用稳定标签区分：

- `@图片1 中的高个子男人是警察。`
- `@图片2 中的矮个子男人是小偷。`
- 后续描述持续使用标签指代，不省略主语。

### 8.4 完整提示词结构

按以下顺序编写：

1. **参考素材列表与用途**（全局风格限定词 + 逐张关键帧的时间锚点身份与命中类型）。
2. **对应分镜映射表**（视频编号、集数、章节、片段、片段时间、镜头编号、分镜原文摘要、提示词时间段、关键帧对齐）。
3. **时长、比例**。
4. **时间戳动作规划**（融合机位、光影、微表情，覆盖分镜每个镜头，0-3 秒 / 3-6 秒…连续规划）。
5. **声音设计**（台词、音效、音乐、旁白）。
6. **全局质感与连续性约束**（含关键帧对齐要求）。
7. **负向约束**：末尾必须加入"禁止生成字幕、文字、LOGO、水印"；只有用户明确要求字幕才可移除"禁止字幕"，仍需禁止无关文字。

### 8.5 从分镜到视频提示词的转换方法

1. **片段选择**：确定本次生成的视频对应哪个片段，保留集/章/片段/时间范围/镜头原文。
2. **素材绑定**：把该片段全部关键帧作为参考素材传入，按时间顺序编号；必要时传入角色/道具资产。
3. **分镜映射表**：在提示词前列出，逐条说明分镜镜头转换到提示词的哪个时间段。
4. **时间戳合并**：把分镜绝对时间戳转成 0-3 秒、3-6 秒的连续动作规划；相邻连续动作可合并，但保留动作因果；不新增分镜表外的剧情。
5. **镜头语言转写**：`[景别｜视角｜机位｜朝向]` 转成自然语言，如"中景，第三人称客观视角，镜头水平右移，正面拍摄林远"。
6. **动作与剧情扩写**：扩写聚焦运镜速度、动作幅度与时长、剧情推进、声音；不重复关键帧图中已有的画面元素；只能补充物理动作细节，不改变剧情结果。
7. **关键帧对齐**：声明"@图片1 为本段首帧""9-12 秒画面必须经过@图片2 状态""以@图片3 为尾帧收束"。
8. **声音整合**：把台词/音效/音乐/旁白合并到对应时间段。
9. **连续性约束**：角色面部、服装、道具、场景、光影、关键帧对齐、动作自然度、无穿模无漂移，末尾加"禁止字幕文字 LOGO 水印"。

**完整提示词示例**：

```text
[是枝裕和风格的电影 · 都市治愈 · 昭和风旧公寓]。@图片1为片段一首帧（命中：空间锚点建立，对应镜头1，00:00），0 秒开场画面必须与其一致。@图片2为片段一 9-12 秒中段锚点（命中：决定性瞬间/道具首次亮相，对应镜头4），POV 俯看铁盒时画面必须经过此帧状态。@图片3为片段一尾帧（命中：情节转折/悬念揭示，对应镜头5），12-15 秒收束画面必须落到此帧状态。@图片4为林远角色资产参考，面部、发型、服装、身高比例以此为准。@图片5为铁盒道具资产参考，尺寸、锁扣位置、划痕分布以此为准。

时长：15秒；比例：9:16

0-3 秒：@图片1 为本段首帧。远景，第三人称客观视角，镜头以 0.6m/s 匀速水平向右平移，背面拍摄林远推开旧公寓木门后停在门框中央约 1 秒后开始迈步进入。 『旁白：父亲走后的第七天，我第一次踏进这里。』 (低音提琴 + 钢琴的舒缓弦律缓缓响起)

3-6 秒：中景，第三人称客观视角，固定机位，从林远 3/4 侧面拍摄他缓缓走进客厅（步频约每秒 1 步），视线从右向左扫过书架上父亲的旧照片，眉头微微收紧。 <木地板轻微吱呀声，两声，间隔约 1 秒>

6-9 秒：近景，第三人称客观视角，跟拍，正面拍摄林远走到书架前停下；他右手缓慢抬至肩高，指尖轻抚玻璃相框边框，停在父亲肩膀位置停留约 1 秒。 <指尖擦过玻璃相框的细微摩擦声>

9-12 秒：切入林远 POV 第一人称特写，手持感运镜俯拍书架第三层层板；林远左手用食指与中指指腹轻轻拂过铁盒盖面。此段画面必须经过@图片2（中段锚点）状态。

12-15 秒：切回第三人称大特写，固定机位垂直俯拍铁盒盖面，铁盒盖面缓缓浮出微小光斑。此段以@图片3 为尾帧收束。 <清晰规律的老式钟表滴答声，节拍约每秒 1 次> (音乐戛然而止，仅剩滴答声)

约束条件：整体保持是枝裕和风格的电影质感、都市治愈基调；0 秒画面与@图片1 一致，9-12 秒经过@图片2 状态，12-15 秒落到@图片3 状态；旧公寓门框、书架、地板、光源方向、色温在片段内连续；林远面部、发型、服装全程与@图片4 一致，禁止漂移；铁盒尺寸、锁扣位置与@图片5 一致；POV 镜头只能出现林远左手与前景铁盒，不能出现完整正脸；动作连贯自然，无穿模无卡顿。禁止生成字幕、任何文字、LOGO、水印；禁止人物面部漂移、服装变化、道具消失、无关角色乱入。
```

> 注：`@图片1` 等是参考素材的常见引用语法，具体以所用工具要求的格式为准（部分工具用"图1""参考图1"或 UI 直接选择）。

### 8.6 质量检查清单

- 提示词已列出分镜映射表，每个时间段可追溯到集/章/片段/镜头/分镜原文。
- 严格遵循分镜，无新增剧情/角色/道具/场景/动作结果。
- 参考素材已包含该片段全部关键帧，每张都声明时间锚点身份 + 命中类型 + 绝对时间点。
- 提示词文字未复述关键帧图中已有画面元素，聚焦运镜/动作/剧情/声音。
- 角色、服装、道具、场景、光影一致。
- 时长、比例、模式、批次数量明确；单批不超过 2 个视频。
- 末尾已加"禁止字幕/文字/LOGO/水印"负向约束。

## 9. 工具适配指南

把本文档映射到任意 AI 工具时，按下表对应：

| 方法论中的能力 | 豆包环境（原技能） | 通用映射建议 |
|---|---|---|
| 交付产物 | 保存文件并通过 present_files 交付 | 将产物保存为 Markdown/图片/视频文件后交给用户；或用工具自身支持的文件交付机制；至少不要在聊天正文里整段堆砌 |
| 文生图 | text_to_image / T2I | 工具的"文生图"功能（如即梦/可灵/Runway/Midjourney/Stable Diffusion） |
| 图生图 | image_to_image / I2I | 工具的"图生图/参考图生成"功能；提示词按 6.7 的"编辑目标+保留项+编辑项"结构撰写 |
| 图生视频 | image_to_video / I2V | 工具的"图生视频/首帧驱动"功能；把关键帧作为参考图传入 |
| 文生视频 | text_to_video / T2V | 工具的"文生视频"功能（无参考图时使用） |
| 参考素材引用 | @图片1 / @视频1 / [img0] 动态编号 | 按目标工具的参考素材引用语法；核心是"每张素材声明用途 + 动态编号一一对应" |
| 联网查热门题材 | general_search | 工具自带的联网搜索/浏览器能力；没有就按题材库直接选 |
| 单段视频时长 | 15s 锁定（模型限制） | 查询目标生视频模型的单段时长上限，分镜片段按上限切分 |
| 角色/场景一致性 | 资产图 + 图生图约束 | 任何工具都适用：先生成设定图，后续生成以设定图为参考图，提示词首句统一风格锚点 |

### 关键适配原则

1. **风格锚点前置**：无论用什么工具，都从剧本阶段锁定一句话风格（"王家卫风格的电影"/"3D 玄幻风格"），所有生成提示词首句沿用。
2. **参考图优于文字**：有资产图就传图，别只靠文字描述——一致性靠参考图而非形容词。
3. **确认门禁保留**：每个阶段交付后停下等用户确认，不自动连跑。
4. **视频提示词只写动态**：画面细节交给关键帧图，提示词只写运镜、动作、剧情、声音，避免双重解释。
5. **批量约束**：单批视频生成数量上限由工具决定，但建议一次不超过 2 个，便于逐段验收。
