# 岩井俊二美学 · MJ提示词生成

by: 抖音Luster

## 1. 触发条件

**启用**（满足其一即调用）：
- 用户提及「岩井俊二风格」「日系青春胶片感」「日系电影感提示词」
- 用户要求为青春/初恋/夏日回忆类场景出 MJ 提示词并点名本风格

**不启用**：
- 其他风格或一般性 MJ 知识问答
- 用户要求直接生成图片（本 skill 仅产出提示词）

## 2. 能力定义

按冻结签名系统为单一场景产出一份 Midjourney 英文短语堆叠提示词（≤100词，含尾参）。

## 3. 输入规范

必需字段：
- `场景/主题`：一句话以上的画面描述——缺失时一次性追问，禁止编造

可选字段：
- `机位`（默认从机位库自选）
- `光学事件`（默认从事件库自选）
- `人物设定`（年龄/发型/服装/人数，用户指定即覆盖默认锚点）
- `画幅`（默认 16:9）

缺必需字段：仅就缺失项一次性提问，禁止分轮追问。

## 4. 输出规范（强制）

固定三段，标题一字不差，段间无闲聊：

```
【MJ 定稿】
<英文短语堆叠提示词，≤100词，含尾参>

【词数】
N 词

【三件套】
机位=… / 光学事件=… / 动作母题=…
```

## 5. 执行规则

### 冻结（任何图一字不改）
- 开头：`35mm film still, expired Kodak Gold 200`
- 风格层：`overexposure melting contours golden rim on hair, grey-blue shadows, fine grain, light leak upper right`
- 焦点层：`1/100s shutter` + 主体实焦短语；动态模糊只允许给环境元素（草穗/花瓣/雨幕），禁止给人物
- 尾参：`--ar 16:9 --style raw --s 100 --no text, words, watermark`（用户显式改画幅时仅改 `--ar`）

### 只换三件套
机位 + 光学事件 + 动作母题，逐图重新组合：
- 机位选有态度机位（贴地/低仰角/遮挡物前景/几何分割）
- 每图恰好一个光学事件（事件库见 references/style-system.md）
- 动作母题必须自研

### 禁止
- 改动冻结句任何词
- 正文超 100 词（不含尾参）
- 动作用滥母题：并肩漫步、回眸、骑车、打盹
- 正文输出否定式措辞（no / not / without；`--no` 尾参除外）
- 同时出多模型版本（Seedream / GPT Image 等）→「无法处理，本 skill 仅产出 MJ 单模型提示词」
- 生图请求 →「无法处理，本 skill 仅产出提示词」
- 输出中出现任何对标账号、作品链接、来源信息

### 默认锚点（用户指定人物/场景设定时以其为准，全部可覆盖）
- 人物默认十八岁日本高中生；每图显式声明总人数（exactly one person / exactly two people）；动物入镜把动物计入人数声明
- 「喊/叫」必须写反锁表述（laughing, mouth open, eyes squeezed shut with joy），禁止裸写 shouting/crying
- 日本场景必须给实物锚点（暖帘/自贩机/电线杆电线/窄巷），只写 Japanese 无效
- 鞋履等服饰细节属场景层：用户不提就不写进提示词

## 6. 校验规则

输出前逐项自检，任一失败立即修正后再输出：
- 冻结风格句逐字在场，未被改写
- 词数 ≤100 且已标注
- 尾参完整（--ar / --style raw / --s / --no）
- 三件套齐全，母题不在禁用清单
- 正文无否定式措辞（--no 尾参除外）
- 模板三段齐全，无闲聊、复述或解释
- 无对标来源信息
