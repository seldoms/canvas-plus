# 签名系统速查

## 冻结句（逐字使用，任何图一字不改）

开头（逐字）：
```
35mm film still, expired Kodak Gold 200
```

风格层（逐字）：
```
overexposure melting contours golden rim on hair, grey-blue shadows, fine grain, light leak upper right
```

焦点层（逐字）：
```
1/100s shutter
```
+ 主体实焦短语（subject tack-sharp / subjects tack-sharp）。动态模糊只允许给环境元素（草穗/花瓣/雨幕），禁止给人物。

尾参（逐字，用户显式改画幅时仅改 --ar）：
```
--ar 16:9 --style raw --s 100 --no text, words, watermark
```

## 色彩公式

过期 Kodak Gold 200：暗部灰蓝（faint grey-blue shadows）× 高光暖黄（warm yellow highlights）× 右上角轻微漏光（light leak upper right）× 细腻颗粒中和数字锐利感（fine grain）× 冷暖分离色调（cold-warm split-toning）。

## 复用骨架（换场景时只换环境层）

有态度的机位 → 单一来源光 + 一个光学事件 → 发丝级动作描写 → 冻结色彩公式 → 一步距离感收尾。

## 结构模板（短语堆叠顺序）

1. 冻结开头（胶片句）
2. 机位 + 场景环境层
3. 人数声明（exactly one person / exactly two people，动物计入）
4. 人物 + 动作母题（发丝级细节）
5. 光学事件
6. 冻结风格层
7. 焦点层
8. 尾参
