# 对口型：片段 + 该镜 TTS 音频 → 口型对齐的新片段

本阶段把**有台词音频产物**的镜头做口型对齐，产物**另存**为新片段（**不覆盖原片段**），
供成片阶段优先取用新片段；它解决的核心诉求是「**改一句台词只重跑对口型这一步，而不是重跑整段视频**」。

## 位置与边界

- **位置**：**片段产出之后、成片之前**。它是**生成型后处理**，不改关键帧 / 成片的主链路语义。
- **不阻塞成片**：成片阶段（`assembly`）的 `requires` **不含本阶段**；成片永远能按原片段出。
  本阶段失败 / 超时 → 该镜成片**回落原片段**，并写**可读 warning**，**绝不因此让成片失败**。
- **产物另存**：对口型产物写在 `run.stages.lipsync.output.clips[]`，**绝不改写** `assembly.output.clips`
  （原片段仍在，可回滚、可对比）；成片只在「交 delivery 的派生副本」上把该镜换成新片段。

## 触发条件（逐镜判定；二者同时满足才做，否则跳过）

1. 该镜**片段存在**（`assembly.output.clips[]` 里有该 `shotId` 且有 `artifactUrl`）；
2. 该镜**有台词音频产物**（`audio.output.audio[]` 里有同 `shotId` 且有 `artifactUrl` 的 AudioCue）。

**无台词镜（无 AudioCue 或音频失败）直接跳过** —— 它的环境音/音效来自片段原声，不该动。

## 输入 / 输出契约

- **输入**：该镜片段（已有产物 URL）+ 该镜 TTS 音频（`audio` 阶段产物，按其 `startSec` 对齐到片段内偏移）。
- **输出**（`run.stages.lipsync.output.clips[]`，每条一次对齐尝试）：
  ```json
  {
    "id": "<源片段 id>-lipsync",
    "shotId": "sh1",
    "sourceClipId": "sh1-clip",
    "sourceClipUrl": "/api/artifacts/.../sh1-clip.mp4",
    "sourceAudioUrl": "/api/artifacts/.../cue.flac",
    "startSec": 0,
    "durationSec": 5,
    "candidates": [{ "jobId": "...", "artifactUrl": "...", "status": "done" }],
    "artifactUrl": "/api/artifacts/.../sh1-clip-lipsync_00001-audio.mp4",
    "status": "done"
  }
  ```
  成片按 `shotId` 匹配：有 `artifactUrl` 的用新片段，否则回落原片段。

## 架构铁律：内容层不得出现模型专属参数

本阶段**不调 LLM**，也不产出任何模型专属提示词 / 采样参数。素材槽（片段、音频）与「缓存兜底开关」
是模型无关事实；把「一次对口型」编译成具体模型的工作流与采样参数（如某 lip-sync 节点的步数、
嘴部强度、帧率、静音补白等）属于**服务端注册表 / 工作流模板**的事，发生在**发起生成请求那一刻**，
由编排器按 `config.pipeline.lipsyncTemplate` 选模板完成 —— **不在本技能产物里、也不在前端**。

## 幂等与「改一句台词只重跑对口型」

- **相同输入跳过**：该镜 `(片段 URL, 音频 URL)` 与上次一致且已有候选/产物 → 不重复入队。
- **输入变化才重跑**：换了台词 → 重跑 `audio` 阶段得到新音频 URL → 再跑本阶段，仅该镜输入变化，
  只重跑**这一镜的对口型**，**绝不重回整段视频生成**（H3 不重跑）。
- **缓存兜底**：同一输入命中 ComfyUI 执行缓存时 `/history` 的 `outputs` 可能为空；
  本阶段每次 attempt 换一个 seed 并给唯一 `OUTPUT_PREFIX`，并在拿不到产物路径时按
  `OUTPUT_PREFIX` 从输出目录**按文件名回落**取回产物 —— **不得假定提交后一定拿得到产物路径**。

## 提示词模板

本阶段不依赖 LLM 编排，也无文本提示词；模型无关事实（片段 + 音频素材槽、唯一输出前缀）到生成参数的
映射由编排器确定性完成，真实入参由编排器按所选工作流模板构造。下方仅为阶段形状占位。

```json
{ "clips": [] }
```
